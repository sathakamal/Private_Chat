# P2P Chat - Private Video Calls & Chat

End-to-end encrypted chat for couples. WebRTC P2P = your messages never touch the server.

## Features
- ✅ Video calls (E2E encrypted)
- ✅ Text chat (P2P, server never sees)
- ✅ Voice messages (fixed!)
- ✅ File transfer (photos, docs)
- ✅ Screen sharing
- ✅ Dark mode
- ✅ Install as PWA on phone

## How to use
1. Open on both phones
2. Enter same room code on both
3. Start chatting/calling!

## Deploy to Render (free)
1. Push to GitHub
2. Connect to Render.com
3. Auto-deploys!
